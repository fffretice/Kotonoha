言叶 Kotonoha 0.7.3
本地日文屏幕翻译 · Apple Silicon · macOS 14 或更新系统

安装
将「言叶 Kotonoha.app」拖进「应用程序」。
此分享包不含模型权重。首次使用请点击「选择模型」，选择你自己的兼容 llama.cpp 的 GGUF 文件，再点击「加载模型」。
优先针对 Qwen3 8B 量化模型与非思考模式调试；其他模型需自行验证翻译质量。
目前使用本地 GGUF 文件，不直接连接 Ollama 服务、云端 API 或 ChatGPT 账户。
模型文件需保留在所选位置。换位置后请重新选择。

范围
全屏：系统选择器中选择一个显示器。
框选区域：先拖动框选，再选择该区域所在的显示器。
窗口选择：直接选择要翻译的窗口。
选择成功后会立即刷新区域预览。播放内容改变分辨率或窗口大小后可重新选择，无需重启。
如之前正在翻译，重选后会自动继续。

显示
默认「融入背景」：每句初次显示时从原文字周围取色，然后固定该句的底色、位置和字号，不再持续重新取色。
字号可在偏好设置统一调整，长句自动换行。
短暂OCR错字会通过本地文字图像匹配避免清空译文；实际换句仍会更换覆盖。
可在偏好设置切换深色/浅色对话框。

对白节奏与翻译
识别会持续采样，不再每次识别结束后额外固定等待。底部「模型生成耗时」仅指模型请求时间，不含识别和文字停稳等待。
偏好设置中的「自动识别」会在发现逐字补全时等待短暂停稳；一般字幕仍及时翻译。
文字一个个出现的游戏可选「逐字对白」，整句直接出现的视频字幕可选「实时字幕」。
默认把同一段换行合起来翻译；除非确有需要，请勿启用逐行独立翻译。
同一对话框继续补字或追加行时，已有译文保留在原位；新的完整译文准备好后直接接替，覆盖框固定左上角和底色向下扩展。整段换成下一句时移除旧译文。
后半句补出后仍会重新翻译完整句，不把前半句译文误当作完整句；人物名可通过术语表指定译法。

控制
Control + Option + T：开始/暂停
Control + Option + R：框选区域
Control + Option + H：显示/隐藏译文
关闭主窗口后，菜单栏「言」仍可控制；菜单栏选择「退出言叶」才会卸载模型并结束共享。

隐私
画面、识别文字与翻译都在本机处理，不上传。模型子进程仅监听本机随机端口并使用每次启动的随机密钥。
对话记录只在当前进程内保存；导出需自行点击。

已知限制
OCR艺术字、描边字和低清字幕仍可能识别不准，译文需自行判断。模型性能也取决于GPU负载。
当前窗口移动后建议重新选择以对齐覆盖层。
全屏排除本App覆盖层在macOS 15.0.1验证，其他系统仍需验证。
支持选择约18.6GB的Qwen3-30B-A3B Q4_K_M。模型文件超过20GiB时会提示选择更小的版本；运行还需要额外上下文与计算内存，文件大小并非总内存占用。
仅包含arm64版本，不支持Intel Mac。
